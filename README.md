
# Simple Calculator

## Project Information
- Course: Object-Oriented Programming (OOP)
- Activity: CIE-2 Activity-6
- Application: Simple Calculator
- Programming Language: Java
- GUI Framework: Java Swing and AWT
- IDE: Visual Studio Code

## Description
This project is a Simple Calculator developed using Java Swing.
It provides a graphical user interface to perform basic
mathematical operations.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Percentage calculation
- Decimal number support
- Clear button
- Delete button
- Positive and negative number conversion
- Division by zero error handling

## OOP Concepts Used
- Classes and Objects
- Inheritance
- Interfaces
- Method implementation
- Event Handling
- Layout Managers

## Technologies Used
- Java
- Java Swing
- Java AWT
- ActionListener

## How to Run

1. Install Java JDK.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

   javac Calculator.java

5. Run the application:

   java Calculator
